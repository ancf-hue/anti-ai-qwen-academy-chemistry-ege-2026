# Anti-AI Qwen Academy | Chemistry EGE-2026 🧪

![License](https://img.shields.io/badge/license-MIT-green)
![Language](https://img.shields.io/badge/lang-RU%20%7C%20EN-blue)
![Offline](https://img.shields.io/badge/offline-ready-orange)

A comprehensive, free, and offline educational tool designed to help students prepare for the **Russian Unified State Exam (EGE) in Chemistry 2026**. 

This project is part of the **Anti-AI Qwen Academy** initiative, focusing on critical thinking, verification of facts, and independent problem-solving rather than blind copying from AI sources.

## ✨ Key Features

*   **Bilingual Interface (RU/EN):** Switch seamlessly between Russian and English using the button in the top-right corner. All questions, chemical formulas, explanations, and UI elements are fully translated.
*   **Complete Exam Simulation:**
    *   **34 Tasks:** Covers all 28 Part 1 (short answer) and 6 Part 2 (extended response) tasks according to the official FIPI structure for 2026.
    *   **Interactive Trainer:** Multiple-choice questions with **randomized option shuffling** to prevent guessing patterns.
    *   **Instant Feedback:** Correct answers appear only after submission, accompanied by detailed theoretical explanations and source references.
*   **Exam Timer:** Built-in countdown timer with presets:
    *   **Chemistry EGE:** 210 minutes (3 hours 30 minutes).
    *   **Practice Mode:** 60 minutes.
    *   Visual warnings when time is running low (<5 mins) and critical (<1 min).
*   **Preparation Tools:**
    *   **Checklist:** Interactive progress tracker for key topics (Atomic Structure, Bonding, Inorganic/Organic Classes, Calculations).
    *   **25-Day Study Plan:** Structured roadmap for Grade 11 students.
    *   **Criteria Guide:** Detailed breakdown of grading rules for Part 1 and Part 2.

## 🚀 How to Use

1.  **Download:** Click the green `Code` button > `Download ZIP`.
2.  **Extract:** Unzip the file on your computer.
3.  **Run:** Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
4.  **No Installation Needed:** The app runs entirely client-side. No server, no database, no internet connection required.

## 📂 Project Structure

*   `index.html`: The single-file application containing HTML, CSS, and JavaScript.
*   `favicon.ico`: Optional icon for browser tabs.

## 🛡️ Privacy & Security

*   **Zero Tracking:** No analytics, cookies, or data collection.
*   **Local Storage Only:** Progress (answers, checklist state) is saved temporarily in your browser's local storage and resets upon page reload unless configured otherwise.
*   **Open Source:** Code is available for inspection and contribution.
